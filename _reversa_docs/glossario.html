Glossário

Os termos que o código e as specs usam. Extraídos do glossário de reversa-sdd/domain.md. Cada cartão tem âncora própria (#concept-…) para links diretos.

Linha (t_line)

Unidade de trabalho: o texto digitado depois do prompt e todo o estado derivado dele

Fonte: minishell.h 🟢

Token (tks)

Pedaço da linha separado por espaços e operadores, ainda com aspas

Fonte: tokenizer.c 🟢

Token limpo (ctks)

Token sem aspas, depois da expansão

Fonte: clean_tokens.c 🟢

Lexema / categoria (lex)

Classe do token: WORD, VAR, PIPE, REDI, REDO, REDA, HERE

Fonte: lexical_analyzer.c 🟢

WORD

Palavra literal

Fonte: 🟢

VAR

Palavra com $ que precisa de expansão

Fonte: 🟢

PIPE

Operador \|

Fonte: 🟢

REDI

Redirect Input: <

Fonte: 🟢

REDO

Redirect Output: > (trunca)

Fonte: 🟢

REDA

Redirect Append: >>

Fonte: 🟢

HERE

Here-document: <<

Fonte: 🟢

Nó (t_pipe_list)

Elemento da lista de execução: um comando ou um operador com seu alvo

Fonte: make_list.c 🟢

Comando

Nó cujo args[0] não é categoria de operador

Fonte: is_command 🟢

bin

Caminho absoluto do executável, o literal "builtin", ou NULL

Fonte: list_generation_bin.c 🟢

Builtin

Comando interno: echo, cd, pwd, export, unset, env, exit

Fonte: builtins_utils.c 🟢

Tabela (t_hash_table)

O "ambiente" do shell: variáveis exportadas e ?

Fonte: hash_table/ 🟢

Status code / $?

Código de saída do último comando, guardado na chave "?" da tabela

Fonte: exec_list.c 🟢

Heredoc

Texto digitado até uma linha delimitadora, entregue como stdin

Fonte: here_doc*.c 🟢

Delimitador

args[1] do nó HERE, já sem aspas

Fonte: 🟢

Facade

Função facade(), ponto único que orquestra o processamento de uma linha

Fonte: README, facade.c 🟢

Miau

Identidade do projeto: prompt miau> , nome MiauShell, "feito por pessoas que amam gatos"

Fonte: README 🟢
