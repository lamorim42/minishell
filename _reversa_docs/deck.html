  1. minishell

    Um subconjunto do bash em C, feito na 42 São Paulo. Documentado como está: o que o código faz hoje, com os bugs conhecidos.

  2. Propósito

    • Prompt interativo miau> com GNU Readline
    • Execução de programas pelo PATH, pipes, redirecionamentos e heredoc
    • Variáveis de ambiente e $?
    • 7 builtins: echo, cd, pwd, export, unset, env, exit
    • Ctrl-C, Ctrl-D e Ctrl-\

  3. Como uma linha percorre o shell

    • Ler: readline, aspas balanceadas, comentário
    • Analisar: tokens, lexemas (WORD, VAR, PIPE, REDI, REDO, REDA, HERE) e gramática
    • Expandir: $NOME e $?, depois remover aspas
    • Montar: lista duplamente encadeada de nós
    • Executar: heredoc em filho, abrir fds, fork/execve, esperar, gravar $?

  5. Decisões que moldam o código

    • Arrays paralelos de tokens (tks, lex, ctks)
    • Ambiente em tabela hash própria (149 buckets), com $? como chave
    • Heredoc lido em processo filho, antes dos comandos
    • Builtin roda no shell só quando é o último nó
    • Uma única variável global (regra da 42)

  6. Cuidado: casos críticos

    • Valor auto-referente (A='$A') trava o shell (RX-06)
    • Falha ao abrir arquivo de saída derruba o shell (BUG-01)
    • Heredoc maior que ~64 KiB trava (RE-09)
    • ft_strncmp por prefixo ignora comandos como P e $NOPE ls (BUG-20)
