Módulos

Cada nó é um arquivo; cada aresta é "o arquivo A chama uma função definida no arquivo B", com espessura proporcional ao número de chamadas. Os nós com contorno vermelho fazem parte de um ciclo de dependência. Arraste os nós, use a roda do mouse para aproximar e passe o mouse para ver os detalhes.

Legenda
  • Nó: arquivo. Tamanho proporcional ao LOC. Cor: pasta.
  • Aresta: dependência por chamada de função. Espessura proporcional ao número de chamadas.
  • Contorno vermelho: o arquivo faz parte de um ciclo detectado.
