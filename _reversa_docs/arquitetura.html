Arquitetura 3D

Cada prédio é um arquivo do código. A altura é o número de linhas (LOC) e a cor é a complexidade ciclomática aproximada, do dourado (simples) ao vermelho (complexa). Cada distrito é uma pasta. Arraste para girar, use a roda do mouse para aproximar e passe o mouse sobre um prédio para ver os detalhes.

Legenda
  • Altura do prédio: linhas de código (LOC, sem linhas vazias e comentários).
  • Cor: complexidade ciclomática aproximada (1 + if/while/for/case/&&/||/?).
  • Distrito (chão colorido): pasta de origem.
  • Prédios com borda vermelha fazem parte de um ciclo de dependência.
